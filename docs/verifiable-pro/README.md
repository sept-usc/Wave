# Companion explainer

The [English](en.md) and [Chinese](zh.md) drafts explain Wave for
[verifiable.pro](https://verifiable.pro/), following the project's observation
mechanism through its size-bound checks, evidence and practical limitations.
**These are review drafts, not published articles.**

The text was generated through the existing daily editorial pipeline using
OpenAI Codex, then reviewed against the paper and artifact. The publication's
editor Mengyuan Li co-authored Wave; both editions disclose that relationship.
No new GPU inference or full solver reproduction was performed for this write-up.

These copies use GitHub-friendly image links in place of the site's native
video players. Site-internal article links are expanded to full URLs. The
manuscript hashes record both the website sources and these formatted copies.
Original animations, static fallbacks and editable sources are in
[`../figures/`](../figures/).

The final bilingual preview and exact artifact hash are retained in the
pipeline's editorial review record. Publishing is a separate editorial action.
Once published, the planned English and Chinese article paths can be linked
from the project homepage; until then, the presentation badge links to the
publication homepage.
